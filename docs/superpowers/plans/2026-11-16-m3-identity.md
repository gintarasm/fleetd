# M3-A: agent identity, `fleet.parent`, scope and quotas — plan

Issue #102 · spec §1 (`docs/superpowers/specs/2026-11-16-m3-satellite-design.md`) · ADR 0072.

## Shape

- **fleet-node owns identity and the tree** (testable without sockets):
  - `scope.rs` (new): `Caller {User, Agent(id)}`, `Quotas`, the spawned-by `Tree` (parent by `fleet.parent`, resolved through the replacement records), descendants / depth / running children, label narrowing, the `[node]` config parser.
  - `token.rs` (new): 32 bytes from `/dev/urandom`, hex, SHA-256 digest (`sha2`, already in the lockfile).
  - `store.rs`: table `agent_tokens(agent_id PK → agents ON DELETE CASCADE, digest BLOB UNIQUE)`, `SCHEMA_VERSION` 8. Lookup only matches running agents; exit and lost-marking delete the row.
  - `node.rs`: `LiveAgent.pid` (new `AgentHost::pid`), `FLEET_AGENT_TOKEN` in the env (set last, like the id), `resolve_caller(session, token)`, `spawn_by` / `spawn_attached_by` / `restart_by` (quota + narrowing + `fleet.parent` under a spawn gate), `is_descendant`, `list_visible`, `SpawnRefused` broadcast.
- **fleetd** — `server.rs` gets small hooks only; the request table lives in `scope.rs` (new):
  - handshake: `peer_cred().pid()` → `getsid` → `node.resolve_caller(..)`; conflict → `HandshakeReject`.
  - every request from `Caller::Agent` passes `scope::check` (boxed future, user path untouched); `ls` is filtered; `rm --exited` rewritten to the caller's descendants.
  - quotas from `<state-dir>/config.toml` `[node]`.
  - `SpawnRefused` forwarded to every connection.
- **proto**: `Hello.agent_token = 40`, `Event.spawn_refused = 40`, `message SpawnRefused { parent, reason }`.
- **client/CLI**: the CLI sends `$FLEET_AGENT_TOKEN`; `forbidden:` → exit 3; `skill` and `daemon upgrade` refused client-side under `FLEET_AGENT_ID`.

## Steps (test-first, one commit each)

1. Proto fields + client token plumbing (struct literal fixes).
2. Token generation/digest + store table + migration tests.
3. `scope.rs`: tree, descendants, depth, narrowing, quota checks, config parser — unit tests.
4. Node: pid, token env, revocation, `resolve_caller` — node tests (session = agent pid, token, conflict, revoked after exit, restart → new token).
5. Node: `spawn_by` (parent label, narrowing, quotas, `SpawnRefused`) — node tests incl. 4th level / 9th child / 31st agent, user never refused.
6. fleetd: handshake identity + request scope table + list filter + forwarder — protocol tests over real sockets with agents running `fleet`.
7. CLI: token in hello, exit 3, client-side refusals — CLI tests (child agent's `fleet` with/without token, token-less process in a session, cross-token rejected, user sees all).
8. Handoff: tokens and sessions survive `daemon restart` (test).
9. ADR 0072 amendment for builder decisions; clippy, fmt, full tests; PR.
