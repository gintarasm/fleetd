# M3-E plan: mailbox, exit reports, broadcast, `fleet wait` (#106)

Spec §3, ADR 0034 §1–3 and §5. Decisions made while building are in ADR 0076.

## Steps (each test-first, one commit or a few)

1. **Store (schema v9).** `messages(id, recipient NULL=user → agents ON DELETE CASCADE, sender NULL=user, kind, body, status, exit_code, created_ms)` with an index on `(recipient, id)`; `inbox_marks(mailbox PRIMARY KEY /* 0 = the user */, last_read)`. Insert with retention (1,000 per agent, 10,000 for the user); read after a cursor; read marks; latest status of a sender. `replace_agent` moves the old agent's mailbox and mark to the new id; `forget_agent` drops the mark (messages cascade). Lost-marking posts `lost` reports. Migration test + fresh-vs-migrated schema test.
2. **Proto (fields 55–64).** Requests `SendMessage = 55`, `ReadInbox = 56`, `Wait = 57`; responses `MessagesSent = 55`, `Inbox = 56`, `WaitResult = 57`. `Message`, `MessageKind`, `WaitState`, `WaitMatch`. Boxed where large (`frame_stays_small`). Round-trip test.
3. **Node (`fleet_node::node::mailbox`).** `send_message(caller, …)` (recipients: D(a), parent, user; broadcast over running children/descendants/selector), `inbox(caller, since)`, exit reports from `NodeSink::on_exit`, `status_changed` hook (the seam M3-D's `fleet report` calls), an in-node `broadcast` of `Notice`s, `wait_check(caller, targets, states, notice)`. Unit/integration tests in `fleet-node/tests/mailbox.rs`.
4. **fleetd.** Scope rows for the three kinds; `Wait` runs as a task on the connection (not counted as in flight, so it never holds off a restart; aborted when the connection ends), answering through the outbox; `fleetd/src/wait.rs`. Protocol tests.
5. **CLI (`fleet-cli/src/mailbox.rs`).** `fleet message`, `fleet inbox`, `fleet wait` with the spec's exit codes; `wait` reconnects across `fleet daemon restart`. End-to-end tests with real agents (as `tests/scope.rs`).
6. **ADR 0076**, fmt, clippy, full test run, PR.
